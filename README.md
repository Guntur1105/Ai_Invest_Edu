## 📱 About The Project

**AI Invest Edu** is a mobile application built with Flutter that focuses on investment education.

The application aims to make investment knowledge more accessible, understandable, and engaging through a modern mobile experience and AI-powered educational features.

Whether you are a beginner or someone interested in learning more about investments, AI Invest Edu aims to provide a convenient learning environment.

## ✨ Features

- 📚 **Investment Education** – Learn fundamental investment concepts.
- 🤖 **AI Assistant** – Explore investment-related topics with AI-powered assistance.
- 📊 **Investment Insights** – Access educational information about investment.
- 🎯 **Beginner Friendly** – Designed to make investment learning easier.
- 📱 **Modern Mobile Interface** – A clean and intuitive Flutter-based experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ai_invest_edu.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ai_invest_edu
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
